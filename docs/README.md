# Documentation index

This folder holds the design authority for the repository. Agents read it in the order below and open only the sections a task names.

## Layout

```text
docs/
  README.md                     this index
  adr/                          architecture decision records (source of truth)
    ADR-IMT-0001-ARCH.md        L1  backend base                (run 1)
    ADR-IMT-0002-LENS.md        L2  analytics layer             (run 2)
    ADR-IMT-0003-PRED.md        L3  predictive layer            (run 3)
  ARCH-0001-algorithms-and-backend-patterns.md   algorithm and backend pattern notes
  experiments/                  pre-registered experiment sheets (L3), `_TEMPLATE.md`
  runs/                         one report per autonomous run: `RUN-<run-id>.md`
  api/openapi.json              public API contract for the frontend (generated by `make openapi`)
  runbooks/go-live.md           how to switch from mock data to live sources
  compliance/                   processing-activities record (habeas data)
  contracts-freeze.md           which shared contracts are frozen and who may change them
```

## Source-of-truth chain

ADRs, then `SPEC.md`, then `TASKS.md`, then code and tests (see `AGENTS.md`). Inside an ADR, a higher-numbered amendment wins over the base text (E2 over E1 over base).

## Layers and runs

| Layer | ADR | Scope | Run |
| --- | --- | --- | --- |
| L1 | ADR-IMT-0001-ARCH v2.3 (accepted) | Backend base: ingestion, data, services, events, security, CI/CD, base reporting | 1 (current) |

| L3 | ADR-IMT-0003-PRED v1.2 (accepted) | Predictive: ML/NLP/graph components, experiment protocol, territory | 3 |

Run 1 must leave L1 consistent and ready for L2 and L3 (ADR-IMT-0001 section E2.3). It must not implement L2 or L3 requirements.

## Rules for editing

- `docs/adr/` is exported from the project vault. Do not edit the ADRs here. A conflict between an ADR and the code is resolved by fixing the code or recording the conflict in the run report.
- Language: ADRs are Spanish. Everything else in the repository is English (`AGENTS.md`).
- Experiment sheets use `docs/experiments/EXP-NNN-<component>.md` (L3).
